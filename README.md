# PISICA - Multiplayer Soulslike Game

## Description

PISICA is a multiplayer Soulslike game developed as an academic project using Unity.

## Technologies Used

- Unity
- C#
- Unity Netcode for GameObjects
- Shader Graph
- Particle System
- GitHub
